# Dataset Card - insurance_sales_dialogue_dataset v2
- Conversations: 1200; train 812 / validation 164 / test 224. Grouped by scenario and normalized transcript.
- Turns: 20,396; all `source_type=synthetic`, `source_dataset=scenario-generator`.
- Labels per turn: intent(9) / emotion(8) / need(9) / objection(11) / stage(11) / PPO action(16) / strategy taxonomy v1.1(16) / yes_yes + stage / reaction / purchase_intent[0,1] / outcome
- Profiles: 3,000 fully synthetic records with age, household, budget, coverage, personality, patience and initial estimates.
- Objection dataset: up to 5,000 derived records with actual associated agent response text and synthetic source provenance.
- External references: MultiDoGO, CaSiNo, Deal-or-No-Deal, GoEmotions, MELD, EmpatheticDialogues, Banking77; metadata only in the default experiment.
- Quality: taxonomy, action/strategy consistency, duplicate IDs, provenance and numeric-range validation.
- Split audit: 572 indivisible scenario/transcript groups; 51 duplicate transcripts grouped to prevent cross-split leakage.
- Balance: synthetic ratio 1.0. Repeated turn wording is expected and reported (20,325 repeated texts).
- Labels and outcomes are generated by rules, not human annotations. `labels_observed=false` and source fields document this.
- Synthetic emotion and stage labels have limited connection to utterance wording; their measured NLP accuracy cannot establish real-customer performance.
- v2 changes: grouped splitting, consistent objection utterances, fact-grounded agent responses, numeric purchase-intent changes, provenance and complete profile records.
